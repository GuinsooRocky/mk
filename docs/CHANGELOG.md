# 更新日志

全部安装包：[Releases](https://github.com/GuinsooRocky/mk/releases)

## v0.4.4

修复：口语数字不再被错转成阿拉伯数字——腾讯云识别关掉自带 ITN（`ConvertNumMode=0`，"一个"不再变"1个"），数字转换收权给本地可控的 NumberNormalizer；成语「千万/万一/万万」加黑名单（"千万小心"不再变"10000000"，而"三千万/一千万/二十一个"照常转）；自学字典加入库门槛（整句 >12 字、纯"一↔1"数字写法差异一律拒学）并清洗存量残渣（`[object Object]`/整句/ITN 残留），"DEV"→"d一v" 误识加兜底。

## v0.4.3

优化：代词/虚词单字口吃（"我我"/"有有"/"是是"）≥2 次即压成一次——这些字不构成合法叠词、叠出来必是口吃；其余单字仍保持 ≥3 次起压，护住"看看/试试/好好/天天/个个"等合法叠词不误删。配合重排，"我有有我有" → "我有"。

## v0.4.2

修复：短促语气词（"嗯"/"哦"）被过滤成空文本时不再误弹「取消/复制/重新粘贴」兜底盘，直接静默收浮窗（兜底盘只在文本非空、目标 app 真切走时才出）；云端引擎（groq/腾讯）的 URLSession 封 `timeoutIntervalForResource` 总时长上限（per-request 15s + resource 20s），网络半死不活/数据涓流时不再挂死请求，配合上层 deadline 自动回落本地。

## v0.4.1

新增：浮窗交接重做（注入成功即 0.15s 收起，定稿只落目标 app，不再回显最终文本与 input 双份并存）；短句快路径（<1s 录音跳过 live 尾段解码）；菜单用户语言化（「实时预览」「自动学习我的修改」「标准（云端）/ 离线（本地）」，Groq 仅配 key 显示）；单实例守卫 + 浮窗 WindowServer 未上屏自愈；流式 interim 过纠错管线（节流 200ms，预览≈定稿口径）。

## v0.4.0

新增：SenseVoice 实时分段（菜单 toggle，现名「实时预览（边说边出）」，VAD 一遇停顿即吐段、只 append 准确版，cc 终端安全）；引擎锁定中文（auto LID 会把部分中英音频误判成日语吐假名，强制 zh 仍正常出中英混说）；连续长句强切上限 10s→4s（不停顿独白每 4s 出段，不再死等 10s）。
